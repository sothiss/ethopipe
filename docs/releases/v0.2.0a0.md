# Release Notes: v0.2.0a0

**Tag:** `v0.2.0a0`
**Target:** `main`
**Release Title:** `EthoPipe v0.2.0a0 — Canine Behavior Modeling, De-biasing Parser, and Quality Gates`

---

## Summary

EthoPipe `v0.2.0a0` is the first pre-release for the upcoming `0.2.0` minor version. This pre-release packages substantial core feature increments, including the canine behavior Pydantic validation matrix, the automated de-biasing narrative parser, comprehensive property-based testing, and strict code quality/security gates.

---

## Detailed Features

### 🐕 Canine Ethological Modeling & Validation
- **Pydantic v2 Models:** Implemented immutable, strict-typed Pydantic validation schemas (`models.py`) for canine physiological telemetry and ethological observations.
- **Biological Guards:** Hardcoded veterinary bounds (e.g., heart rate constrained strictly between $30$ and $250$ BPM) and behavior classification Enums (`play_bow`, `licking_of_lips`, `looking_away`, `posture_freeze`).
- **Darwin Core Mapping:** Standardized observation metadata mapping to Darwin Core (`dwc:measurementType`, `dwc:measurementValue`) standards.

### 📝 Text De-biasing & Payload Parsing
- **Narrative Parser:** Developed regex-based routines to parse unstructured text inputs and extract structured behavior signals.
- **De-biasing Filter:** Filters subjective, anthropomorphic terms (e.g., "stubborn", "angry") from handler reports to extract objective physiological observations.

### 🛡️ Repository Security & Credential Isolation
- **Secret Mitigation:** Separated credentials and Datadog tokens into git-ignored local `.env` configuration files.
- **Aggressive Git Guards:** Hardened `.gitignore` to explicitly block keys (`*.key`, `*.pem`), credential stores, and configuration files.
- **SAST Isolation:** Configured Datadog static analysis exclusions for the local virtual environment (`.venv`) and `.env` files to prevent diagnostic noise.

### ⚙️ Developer Quality Gates & CI/CD
- **Pre-commit Pipelines:** Wired up automated git hooks for linting (`ruff`), formatting (`black`), typechecking (`mypy` with Pydantic support), and dependency checking (`uv-add`, `uv-check`, `uv-audit`).
- **Custom Local Hooks:** Implemented validation scripts enforcing prompt constraints, temperature clamping (forcing deterministic AI parsing), and log level compliance.
- **Property-Based Verification:** Integrated `hypothesis` to dynamically fuzz biological models with a high frequency of boundary conditions.
- **Granular CI Workflows:** Split GitHub Actions CI pipelines into isolated status checks: `lint`, `tests`, and `schema-validation`.
