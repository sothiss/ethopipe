# EthoPipe Audits & Compliance Archive Directory

This directory archives historical audit reports generated during development, continuous integration, and release verification.

## 📋 Audit Streams

1. **Solo Maintainer Guardrails & Anti-Bloat Audits (`SOLO_MAINTAINER_AUDIT_<timestamp>.md`)**
   - Generated by [`scripts/audit_maintainer_guardrails.py`](../../scripts/audit_maintainer_guardrails.py).
   - Enforces the 5 Pillars of the Solo Maintainer Charter:
     1. Language Monoculture (100% Pure Python >= 3.11).
     2. Strict Dependency Budget ($\le 8$ direct runtime dependencies).
     3. Agent Plugin & Skill Hygiene (zero out-of-scope enterprise cloud skills).
     4. Architectural Simplicity & Cognitive Budget (files $< 600$ lines, zero distributed brokers/daemons).
     5. Toolchain Consolidation (`uv`, `ruff`, `mypy`, `pytest` via `run_qa.ps1`).

2. **Open Source & Code Quality Compliance Audits (`OPEN_SOURCE_COMPLIANCE_<timestamp>.md`)**
   - Generated by [`scripts/verify_open_source_standards.py`](../../scripts/verify_open_source_standards.py).
   - Verifies compliance against JOSS / FAIR scientific benchmarks:
     - Community Governance (OSI License, Citation CFF, CoC, Security Policy).
     - Domain Invariants & Darwin Core standard mappings.
     - Static Type Integrity (Mypy, Ruff).
     - Test Baseline ($\ge 85\%$ pytest coverage + Hypothesis property-based fuzzing).
     - Supply Chain Security (`uv audit`).

---

## 🕒 Audit Frequency & Usage

- **Active Telemetry**: The latest audit reports are always reflected at [`docs/SOLO_MAINTAINER_AUDIT.md`](../SOLO_MAINTAINER_AUDIT.md) and [`docs/OPEN_SOURCE_COMPLIANCE.md`](../OPEN_SOURCE_COMPLIANCE.md).
- **Historical Snapshots**: Every run of `python scripts/audit_maintainer_guardrails.py` or `python scripts/verify_open_source_standards.py` automatically commits a dated snapshot here (`YYYYMMDD_HHMMSS`) to preserve the longitudinal audit trail.
