from datetime import datetime
from pydantic import BaseModel, ConfigDict, Field, field_validator
from typing import Literal, Optional

class CanineObservationRecord(BaseModel):
    model_config = ConfigDict(strict=True, extra="forbid")

    individual_id: str = Field(..., pattern=r"^CANIS-[A-Z0-9]+$")
    event_timestamp: datetime
    ethogram_token: Literal[
        "play_bow",
        "displacement_oral_lip_licking",
        "displacement_pant",
        "pinnae_caudal_retraction",
        "locomotion_avoidance_vector"
    ]
    heart_rate_bpm: Optional[int] = Field(None, ge=30, le=250)
    basis_of_record: Literal["MachineObservation", "HumanObservation"]

    @field_validator("heart_rate_bpm")
    def validate_merck_canine_bounds(cls, value: Optional[int]) -> Optional[int]:
        if value is not None and not (30 <= value <= 250):
            raise ValueError(
                "Physiological anomaly: BPM violates Merck canine boundaries (30-250 BPM)."
            )
        return value

They’re Made Out of Weights: Calibrating Zero-Temperature Foundation Models for Field Ethology

By Alice Severi Gonçalves · Principal Systems Architect

When language models are deployed colloquially, they behave as speculative conversationalists—eager to flatter the human prompter, invent missing context, and assign complex internal emotional states to mute actors. In companion animal welfare science, this tendency is fatal. Veterinary records already suffer from human anthropomorphism; feeding subjective shelter narratives into a temperature-unclamped LLM simply amplifies cognitive bias.

In EthoPipe, we treat large foundation models strictly as zero-temperature deterministic clerical parsers. By hard-clamping the inference parameter to temperature = 0.0 and enforcing structured decoding via the official Google GenAI SDK (response_schema=model_json_schema()), the model is stripped of stochastic drift. It cannot hallucinate motivations, rationalize behavior, or introduce unobserved facts. It acts solely as an atomic transducer mapping natural language into validated kinematic ethogram tokens.

# Clamped Google GenAI SDK configuration enforcing zero-drift schema parsing
from google import genai
from google.genai import types

client = genai.Client()
response = client.models.generate_content(
    model="gemini-3.5-flash",
    contents=raw_handler_prose,
    config=types.GenerateContentConfig(
        temperature=0.0, # Clamped to zero: completely deterministic
        response_mime_type="application/json",
        response_schema=CanineObservationRecord.model_json_schema()
    )
)

De-anthropomorphizing Incident Reports: Replacing Subjective Prose with Type-Strict Kinematics

By Alice Severi Gonçalves · Principal Systems Architect

Canine incident documentation across animal shelters and training yards is paralyzed by moralizing adjectives. Observers routinely describe subjects as "spiteful," "guilty," "stubborn," or "mean." In empirical multi-observer concordance testing, this unstandardized vocabulary yields an inter-rater Fleiss' Kappa score of just κ = 0.22, which is statistically indistinguishable from noise.

EthoPipe bridges this gap by grounding the data dictionary in verified peer-reviewed canine behavior catalogs (Broseghini et al., 2024; de Winkel et al., 2024). Using pre-compiled regex filters and Pydantic v2 validation (ConfigDict(strict=True, extra="forbid")), subjective attributions are stripped and compiled into verifiable kinematic action units—such as oral displacement licking, caudal ear pinnae retraction, or avoidance vectors—and serialized into the Darwin Core relational star-schema.

Cloud Engineering for Veterinary Welfare: Google Cloud Run, Firestore, and CI/CD Guardrails

By Alice Severi Gonçalves · Principal Systems Architect

During Phase 3 of the project's development (awarded through the Google Cloud Launchpad Fellowship under the Cloud Engineering Track with Mentor Me Collective), EthoPipe transitioned from isolated local Docker sandbox environments to fully containerized, serverless cloud endpoints on Google Cloud Run backed by Cloud Firestore.

To safeguard the repository against dependency rot and operational cognitive drag, we codified the Solo Maintainer Guardrails Charter:

  • 100% Pure Python Monoculture: No Node/npm packaging, no compiled C extensions.
  • Dependency Budget: Direct runtime dependencies capped at ≤8 packages in pyproject.toml.
  • Daemon Proscription: Complete rejection of external message brokers (Redis, Celery, Airflow).
  • Continuous Verification: Automated multi-matrix testing across Python 3.11 & 3.12 (43/43 passing pytest suite with 100% coverage) executed with .\scripts\run_qa.ps1.

This disciplined simplicity enabled persistent open-science deposit onto the Zenodo archive with permanent DOI minting (10.5281/zenodo.21211371), preparing EthoPipe for formal review in the Journal of Open Source Software (JOSS).
