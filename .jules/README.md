# Jules Learning Journal (`.jules/`)

This directory contains persistent architectural and security learnings recorded by autonomous code companions (such as **Google Labs Jules** `@google-labs-jules[bot]`).

## Journal Files
- **[`bolt.md`](file:///H:/Projects/ethopipe/.jules/bolt.md)**: Performance optimizations, algorithmic improvements, vectorization, and caching discoveries.
- **[`sentinel.md`](file:///H:/Projects/ethopipe/.jules/sentinel.md)**: Security audits, boundary defenses, input sanitization, and adversarial protections.

## Entry Convention
Whenever a code companion completes a task involving an optimization or security rule, it MUST append an entry formatted as:

```markdown
## YYYY-MM-DD - <Descriptive Title>
**Learning:** <Quantitative or architectural insight gained from profiling or auditing>
**Action:** <Concrete code pattern or validator enforced to resolve the issue>
```
